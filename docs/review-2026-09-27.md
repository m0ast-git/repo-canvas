# Результаты ревью Repo Canvas

27 сентября 2026, версия 0.14.0. Исправлены повторные фоновые вызовы, сделаны читаемый обзор и пошаговые сценарии, добавлены общие лимиты, MCP, хуки и первая карта без модели. Ручная раскладка и исходная история сохранены.

| Пункт ревью | Что изменилось и чем проверено |
|---|---|
| 1.1. Петля Observer | Пустой итог снимает ожидание повторной проверки; новое изменение учитывается один раз. Одинаковая работа не дописывается в журнал. 1000 тиков — один вызов и одна запись; повторные попытки и фоновые квоты ограничены |
| 1.2. Работа и история | Промежуточные статусы не создают отметки. Работа передаётся кратко, подробности запрашиваются отдельно. Новые снимки сжимаются, лишняя копия work убрана. Исходные 39 392 отметки доступны через 125 глав |
| 1.3. Построение | Карточки модулей кешируются по содержимому; импорты извлекаются из синтаксического дерева. Шаги выводятся из связей, ссылки проверяются по ID, общеупотребительные термины переводятся словарём. Есть оценка до старта, настройки расхода и добор сообщений владельца. Фактически проверенный результат сохраняется при незавершённой проверке понятности; продолжение проверено |
| 1.4. Наблюдение | Файлы связываются с модулями без модели. Хуки сообщают начало, файлы и завершение; одна модельная сводка подводит итог хода. Исправлены короткие пути Windows и symlink-пути macOS. Поздние/повторные события не открывают завершённую работу |
| 1.5. Исполнители и расход | Общий журнал всех ролей, ошибок и отсутствующих данных о токенах; ограничения на час/день и видимая пауза. Изоляция Codex вынесена из TEMP. Настоящий полный путь небольшой карты прошёл на CLI 0.153.4 |
| 1.6. Обмен с браузером | SSE и дельты заменяют постоянный опрос. За 20 секунд простоя — ноль запросов state/revision; отключение сервера видно за 241 ms. Файлы сборки с хешами кешируются |
| 1.7. Раскладка и расчёт | ELK учитывает связи. На большой карте считаются маршруты выбранного модуля/области/шага, до 60. Обзор использует агрегаты. Проверка 250/600: обзор 383 ms, фокус области 373 ms |
| 1.8. Доставка | Клиентские библиотеки и Codex убраны из обязательных runtime-зависимостей. Глобальная установка не меняет package.json. Архив около 1.41 MB. Обновление требует SHA-256 и подписанного происхождения, неподписанный пакет отклоняется |
| 1.9. Размер модулей | Графические элементы, обзор, сценарий, состояние, работа, обмен данными и другие самостоятельные части вынесены из main. Промпты архитектора и наблюдателя вынесены в шаблоны |
| 2.1. Обзор | Название, назначение, основные модули, планы и проблемы видны на сводках областей. Встречные агрегаты сохраняют оба цвета. На узком экране области перелистываются |
| 2.2. Подписи | Минимум 12 экранных px на подробном виде; обзорные заголовки крупнее. Проверены 25/40/55/75/100% |
| 2.3. Упорядочивание | Явное действие меняет только незакреплённые элементы. На фикстуре сохранены остальные 249 позиций, отмена восстановила отсутствие закрепления |
| 2.4. Фокус | Видны выбранные связи и метки удалённых концов. Камера не запускает новый расчёт. «Обзор всех связей» возвращает агрегаты большого графа |
| 2.5. Линза | Пара участников шага, номера, действие, условие, итог и полная последовательность. Все четыре настоящих сценария, 36 переходов, клавиатура, Escape и узкий экран проверены |
| 2.6. Главы и возвращение | Главы сохраняют исходные номера и доступ внутрь. «Пока вас не было» показало реальную правку на фикстуре и не повторилось после подтверждения. Сохранённые SVG истории совпали с Live |
| 2.7. Цвет | Шесть различимых семейств. Минимальное CIEDE2000 — 20.79 в светлой теме и 20.30 в тёмной. Контраст проверенных текстов обзора — минимум 5.35:1 и 7.82:1 |
| 2.8. Статусы | В инспекторе объяснено, почему нужна проверка. Ошибки переведены, техническая запись раскрывается отдельно. Постоянная строка построения заменена компактным статусом |
| 3.1. MCP | Шесть инструментов: обзор, поиск, решения, сценарий, объявление и завершение работы. Протокол проверен официальными Client/Server; чтение не пишет карту |
| 3.2. Структура без модели | Сначала файлы и прямые импорты, затем объяснение. Ограничение «подтверждена только структура» обозначено явно; ошибка модели сохраняет первую полезную карту |
| 3.3. Здоровье | Страница показывает расход, ошибки, квоты, паузы, объём данных и незакоммиченные файлы. Лимиты редактируются в настройках |
| 3.4. Проверка полезности | Реализованы протокол пяти вопросов и сохраняемая оценка по версии. Исследование с реальными владельцами на 3–5 внешних репозиториях не подменялось искусственными ответами |
| 3.5. Git | Накопленная прежняя работа сохранена вместе с исправлениями в коммитах. Полный CI проходит вне компьютера владельца. Итог публикации фиксируется после подписанного выпуска |
| 3.6. Позиционирование | README объясняет фактическую ценность: общий контекст проекта, решения владельца, работа агентов и история. Новая рекламная кампания не добавлялась |

Приняты три обоснованных отступления. Исходный журнал не переписан: это сохранило ID, ссылки и прошлую геометрию; шум убран из представления и новых записей. Для существующих снимков применено штатное NTFS-сжатие с проверкой SHA — освобождено около 104 MiB без изменения содержимого. Экспериментальный Codex App Server не вводился: исправлены повторные запуски, выбор установленного CLI, изоляция и ограничения. Ручные позиции не сбрасывались ради экспериментального уменьшения пересечений из ревью.

Настоящее небольшое построение: 74.6 секунды, 3 вызова, 37 259 токенов, проверка фактов и понятности пройдена. С учётом подготовительных успешных вызовов этого эксперимента известно 45 740 токенов; ещё были отклонения из-за несовместимости CLI. Эти числа не являются прогнозом полной карты владельца. Она не перестраивалась платно.

Код проверен 203 unit-тестами и 24 интеграционными проверками; установка и отказ неподписанному обновлению проходят в CI на трёх ОС. Браузерные доказательства — [design-qa.md](../design-qa.md), актуальные ограничения — [implementation-status.md](implementation-status.md). Claude CLI отсутствует, новый полный прогон Kimi, внешние пользовательские исследования и слабый ноутбук не заявляются как проверенные.

Из-за предупреждения Kaspersky массовые локальные тесты прекращены; защита не отключалась. Рабочий сервер оставляется с временной паузой фоновых модельных вызовов. Карта доступна, причина показана в «Состоянии», возобновление выполняется явной кнопкой в настройках.
