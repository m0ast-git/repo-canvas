# Состояние реализации и открытая приёмка

Актуализация: 27 сентября 2026, версия 0.14.0. Требования находятся в [acceptance.md](acceptance.md), устройство системы — в [system-map.md](system-map.md). Этот документ сообщает результаты, а не заменяет требования.

## Подтверждено в текущем проходе

- Исправлены повторная финальная проверка Observer и запись одинаковой работы. В одном процессе 1000 тиков дали один искусственный модельный вызов и одну запись; ожидание проверки снялось. Фоновые резервации, расход и причины пауз сохраняются по проекту.
- `node tests/review-integration.mjs`: 24 проверки без реальных модельных вызовов. MCP Client/Server, хуки и поздние повторы, AST/карточки/структура, SSE, главы, обратимость сжатия, координаты/отмена, оценка по версиям, частичное принятие/resume, отказ недостоверному кандидату, добор всех собственных сообщений фикстуры и сохранение конкурентной инструкции владельца.
- Реальный Codex CLI 0.144.0: короткая проверка подключения прошла за 7.27 s, 8122 токена. Перед ней выявлен и удалён неподдерживаемый флаг skill_search; исходная попытка завершилась до модельного ответа. Это проверка структурированного ответа, а не нового полного построения.
- Реальное построение изолированного проекта прошло на Codex CLI 0.153.4: 74.6 s, три вызова, 37 259 токенов, факты и понятность приняты, два модуля и два сценария. Предварительные попытки обнаружили старый глобальный CLI, не поддерживающий выбранные модели. В checkout приоритет теперь у уже установленной devDependency; опубликованный пакет по-прежнему использует отдельный CLI и не устанавливает Codex как обязательную зависимость.
- Реальная карта: четыре области, 28 сущностей, 48 отношений; все сохранённые ручные x/y совпали до/после. 39 392 исходные отметки представлены 125 главами. ID и ревизии не менялись. API state — 312 022 bytes вместо около 549 КБ в ревью.
- 394 исторических снимка сжаты штатным NTFS-сжатием: логические 243 779 235 bytes занимают 135 066 401 bytes. Экономия 108 712 834 bytes; контрольные SHA журнала, каждого снимка и геометрии совпали. Журнал не переписывался.
- Настоящий браузер: 1440×900 и 390×844, обе темы; обзор, четыре сценария и все 36 переходов, последовательность, клавиатура, здоровье. На изолированной карте проверены редактирование, вторая вкладка, перенос вложенного элемента, undo, упорядочивание с сохранением остальных 249 позиций и снятием нового закрепления при undo.
- В изолированной истории записанные SVG Live и снимка совпали; сравнение и возврат Live работают. «Пока вас не было» показало реальную одиночную правку, сохранило высоту карты и исчезло после подтверждения.
- SSE: 20 s простоя без HTTP-запросов state/revision; остановка сервера обозначилась за 241 ms. Камера не меняла номер расчёта маршрутов.
- Нагрузка 250 объектов / 600 отношений / вложенность 4 / 6 работ: полезный обзор 383 ms; выбранный модуль — 6 маршрутов за 45 ms; область — 24 маршрута за 373 ms. Это Core Ultra 7 255HX, 31.4 GiB RAM, Windows и Chromium 151, без замедления CPU. В исходной фикстуре устранено совпадение прямоугольников первой и шестой работы — невозможная геометрия не является корректным замером роутера.
- Сборки Vite проходили. Полный локальный набор тестов был остановлен при предупреждении Kaspersky; его текущий результат не объявляется зелёным. Отмеченный антивирусом файл повторно не запускался, защита не менялась.
- Итоговый [CI 36287950800](https://github.com/m0ast-git/repo-canvas/actions/runs/36287950800) прошёл на Windows, macOS и Linux: 204/204 unit, 24/24 review integration, build, установка пакета и отказ неподписанному обновлению с восстановлением прежнего runtime. Исполняемый код — commit 34efcaa.
- [v0.14.0 опубликован](https://github.com/m0ast-git/repo-canvas/releases/tag/v0.14.0) через подписывающий workflow. Скачанный архив проверен настоящим gh и тем же helper, который использует updater, с закреплёнными repo/workflow/tag. SHA-256: 656a44b4c93fe645e804d97bc901c67ff7f4a28ed95af15cd1fb2df80e01e991. Архив 1 432 822 bytes, обязательные зависимости по установленным файлам lockfile — 37.4 MiB, Codex среди них отсутствует. Лицензии клиента и workers включены в пакет.

Локальные доказательства: `output/review-2026-09-27/integration.json`, `browser-checks.json`, `data-before-compression.json`, `data-after-compression.json` и PNG. Скриншоты и их охват перечислены в [design-qa.md](../design-qa.md).

## Границы проверки

| Область | Текущее состояние |
|---|---|
| Модельное построение | Полный путь небольшой изолированной карты проверен настоящими моделями. Полная карта владельца не перестраивалась; результат 37 259 токенов нельзя переносить на её размер |
| Claude / Kimi | Claude CLI отсутствует. Прежний Kimi-прогон достиг провайдера и вернул HTTP 500; это исторический результат, не свежая проверка |
| Языки | Tree-sitter даёт синтаксические факты; граф импортов разрешает поддержанные локальные формы. Это не полная типизация и не доказательство поведения |
| Читаемость владельцем | Протокол и версионированный evaluator реализованы. Исследование на 3–5 внешних репозиториях с реальными владельцами не проводилось; искусственные 10/10 не являются продуктовой оценкой |
| Большие карты | Новый критерий — агрегаты и семантический фокус до 60 маршрутов. Полный одновременный libavoid-расчёт всех 600 связей не заявляется; 1000/2500, слабый ноутбук и Safari не проверены |
| История | Проверен выбранный записанный набор маршрутов. Все 39 тыс. состояний визуально не проверялись; прежняя геометрия не исправляется задним числом |
| Поставка | Подписанный выпуск и реальная проверка provenance выполнены. Для фоновой проверки обновлений gh должен быть авторизован в окружении сервера; shell-only авторизация автоматически туда не переносится |

## Передача владельцу

Оставлен один сервер на 127.0.0.1:4173 с временной паузой фоновых моделей. Проверочный Chromium закрыт. Пользовательский Chrome отклонил навигацию с ERR_BLOCKED_BY_CLIENT; обычная перезагрузка не помогла. Защитные настройки не менялись, просьба показать карту именно в этом браузере остаётся ограничена его блокировкой.

Автоматический контроль отклонил удаление своих тестовых каталогов runtime-fixture/model-fixture и промежуточных логов. Повторных попыток обхода не было; они остались в output/review-2026-09-27/. Эти каталоги не вошли в Git и релиз. Исходный events.jsonl после всех проверок сохраняет SHA 6327769e54435a275c57c7e966d045113bdc210bf402defa3cdc5ddc13591fc5.

## Принятые альтернативы ревью

Исходный журнал сохранён ради ID, ссылок и записанного прошлого; шум убран из новых записей и представления глав, место освобождено обратимым сжатием. Полноценный новый storage engine не добавлялся. Codex exec сохранён с устранённой петлёй, ограничениями и home вне TEMP; переход на экспериментальный App Server не потребовался. Ручная раскладка владельца не сбрасывалась ради экспериментальных 117→22 пересечений.

Предыдущий cold-build 0.13.3 от 9 сентября (8:03, 223 774 токена, 6 вызовов) остаётся историческим доказательством в `output/playwright/cold-build-0133-e/`, а не приёмкой этой версии. Облачная синхронизация, командные роли и оплата остаются за пределами задачи.
