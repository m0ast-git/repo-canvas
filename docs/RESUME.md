## Системная модель и принятый путь

Node server → events.jsonl → reducer/cache/history → publicSnapshot/SSE → Query → ELK/libavoid worker → React Flow. Источники/AST/module cards → knowledge/architect → проверка фактов/понятности → атомарное применение с сохранением owner overrides. MCP и хуки сообщают контекст/активность, не доказательство реализации.

Карта владельца: 4 области, 28 сущностей, 48 отношений, 4 сценария. Все 28 узлов и 4 области имеют ручные x/y, они сохранены. Исходный журнал и ID истории не переписывались: 39 392 отметки сгруппированы в 125 глав. Большой обзор показывает агрегаты; подробный расчёт следует выбранной области/модулю/шагу, ≤60 маршрутов. Камера не меняет набор. История показывает сохранённую геометрию выбранного фокуса без нового расчёта.

Ключевые исправления: снятие verificationPending на пустом финале, потребление stamp до перепроверки, idempotent work, persistent retries/usage/quotas, сжатые новые snapshots, лёгкий state/work-detail, инкрементальные карточки и импорты, derived flow steps, fact-verified partial/resume, owner backfill, SSE/fallback, readable overview/scenarios/history/health, MCP6tools/hooks/skeleton/evaluator, лёгкая поставка и gh attestation.
