# Repo Canvas

Локальная интерактивная карта проекта. Её задача — помочь владельцу за 1–2 минуты понять основные сценарии, связи частей системы, основания решений, текущую работу и историю.

Перед нетривиальной задачей прочитай `AGENTS.md`, `docs/README.md`, `docs/system-map.md` и `docs/RESUME.md`. Действующие требования и критерии проверки ищи через `docs/README.md`; текущий ход долгой задачи хранится только в `docs/RESUME.md`. Не считай старые отчёты доказательством состояния нынешней версии.

Общайся с владельцем по-русски, ясно и без технического жаргона. Выбирай самое простое рабочее решение в рамках текущей задачи. Сохраняй пользовательские данные в `.repo-canvas/` и чужие незавершённые изменения. Перед запуском сервера проверь действующий процесс; после работы убери только свои временные процессы и файлы.

Изменения проверяй на затронутом пользовательском сценарии. Для интерфейса обязательно смотри результат в браузере на разных масштабах и при движении; одних тестов или сборки недостаточно.
